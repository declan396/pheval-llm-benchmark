Key Findings

Exomiser clearly outperforms both LLM approaches at the gene level (58.4% top-1 vs 12.7% and 9.7%). This is consistent with the published MALCO benchmark (Reese, Chimirri, Bridges et al., Eur J Hum Genet, 2026) which showed Exomiser outperforms LLMs for disease-level diagnosis on 5,213 cases.

Claude phenotype-only (12.7%) slightly outperforms Claude + Exomiser assisted (9.7%) under corrected benchmarking. This is likely because the 5-gene constraint penalises the Exomiser-assisted approach more severely — when Claude anchors on Exomiser's top candidates, it may return fewer unique genes and miss the correct answer more often.

Gene-level prediction is harder than disease-level prediction. One gene may be associated with multiple diseases and one disease may be caused by multiple genes. The MALCO paper notes this distinction explicitly — our lower LLM performance relative to MALCO's disease-level results is expected.

Methodology Correction

01
Add gene interpretations to phenopackets

Phenopackets generated by phenotype2phenopacket only contain a diseases field (OMIM ID) — no causal gene. Used p2p add-genes with HPO genes_to_disease.txt to inject interpretations into 158/200 phenopackets. 42 patients excluded (no known Mendelian gene).

02
Rewrite converter using generate_gene_result

Replaced manual parquet creation and true_positive flagging with PhEval's generate_gene_result helper. PhEval reads the interpretations field from synthetic_patients_with_genes/ to determine true positives internally.

03
Stem matching via lookup CSV

LLM results named patient_001.json; gene-annotated phenopackets named OMIM_100700_patient_1.json. Used synthetic_patients_lookup.csv to map between naming conventions. Approved approach confirmed by Yasemin Bridges.

04
Rename Exomiser results for fair comparison

Exomiser parquet files renamed from patient_001-gene_result.parquet to OMIM-named equivalents using the lookup CSV. Both LLM and Exomiser benchmarks now use identical phenopacket directory and true positive identification method.
